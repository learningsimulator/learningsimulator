n_subjects
**********

Specifies the number of subjects (individuals) in a simulation.

Syntax
------

::

  n_subjects = n

where n is a :ref:`scalar expression<scalar-expressions>` evaluating to a positive integer.

Description
-----------

``n_subjects = n`` sets the number of subjects to ``n``.

When ``n_subjects`` is greater than 1 and ``random_seed`` is not set,
subjects are simulated concurrently using multiple threads, which can
improve performance. See :doc:`random_seed` for details.

Examples
--------

::

  n_subjects = 100

sets the number of subjects to 100.

::

  @variables p = 50
  n_subjects = 100 + p

sets the number of subjects to 150.
